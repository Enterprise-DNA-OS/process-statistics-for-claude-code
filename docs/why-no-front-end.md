# Why a database and conversation

The weekly process review asks which measurements changed, which limits were used and who is investigating. Those questions can be answered from owned records. The CLI performs the calculation and keeps its inputs with the saved result. The coding agent explains the result; it does not invent measurements or approvals.

A screen offers interactive charts, drag-and-drop worksheets, mobile collection and direct instrument controls. This base has none of those. It produces read-only HTML summaries, analysis records and investigation documents. Enterprise DNA can build the collection connections and business views needed for a custom version. Statistical review and validation remain explicit work.

Run npm run view for review summaries and npm run docs for saved analysis and investigation records. Edit brand.json for business name, logo and colours. Ask /new-view for an additional read-only report. There is no web server, no public write endpoint and no automatic sending.
