# Make it yours

Read CLAUDE.md and docs/methods.md. Ask for the field or rule and the intended business outcome. Inspect the affected process and current migration. Create the next numbered migration; never rewrite an applied migration or saved analysis. Extend the one CLI and the relevant command recipe.
